## Embedding model

`nomic-ai/nomic-embed-text-v1.5` — licensed under Apache-2.0.

- Model card: <https://huggingface.co/nomic-ai/nomic-embed-text-v1.5>
- Authors: Nomic AI

The installer downloads the model from HuggingFace Hub at install time. The
model repository revision (`e9b6763023c676ca8431644204f50c2b100d9aab`) is
pinned and recorded in the embedding input identity. The minimum supported
`sentence-transformers` / `transformers` versions provide a built-in Nomic
text implementation, so runtime model loading explicitly disables
`trust_remote_code`.
**This project does not redistribute the model weights.**

The repository does include `knowledge_base/embedding_seed_v2/`: derived
float32 embedding vectors generated by that model from this project's scoped
School/evidence documents. These numeric outputs are not model weights. Their
manifest records the model revision, input profile, corpus fingerprint, and
SHA-256 of each shard so the runtime can verify identity and integrity before
reuse.

## Headless browser

`chromium` — open-source browser project (BSD-style license; see
<https://chromium.googlesource.com/chromium/src/+/main/LICENSE>).

Downloaded by the `playwright` dependency from Microsoft's Playwright CDN
at install time. Used solely to render chart images for analysis output
(no browsing, no network requests other than loading our local HTML
template).

## Charting library

`lightweight-charts` — Apache 2.0 — <https://github.com/tradingview/lightweight-charts>

A small JavaScript chart library bundled into the chart-rendering HTML
template. Used in headless chromium to produce K-line image output.

## Knowledge base content

The 726 concept cards and 1,282 case cards under `knowledge_base/` are
**original structured summaries** authored by this project from analysis
of publicly available educational content spanning multiple trading Schools.
They do not contain verbatim copies of source material;
each card is a paraphrased, schema-structured representation of trading
concepts for research and educational purposes.

The School/source-evidence v2 collections are deterministic projections of
those same cards, not newly imported third-party text. They preserve declared
source-collection metadata and deliberately skip content whose provenance
cannot be assigned without inference.

If you believe a card contains material that should be removed or
attributed differently, please open an issue.
